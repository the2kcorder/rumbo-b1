# Rumbo B1

Lern-App für die Spanisch-B1-Prüfung (UNIcert I): Tagesplan, Karteikarten, Lückentexte, Formen, Lesen, Hören, Aufsätze.

Läuft im Browser: https://the2kcorder.github.io/rumbo-b1/

Der Lernstand wird auf dem jeweiligen Gerät gespeichert. Unter „Fortschritt“ lässt er sich als Datei sichern und wiederherstellen.
